# ASX SEPA Scanner — Ultimate One-File

Upload only `app.py` and `requirements.txt` to the root of a GitHub repository, then deploy `app.py` with Streamlit Community Cloud.

The app includes technical screening, momentum, relative strength, Stage 2, base/VCP proxies, pivot/breakout checks, best-effort fundamentals, risk sizing and charts.

This is a mechanical SEPA research aid, not an automatic trading system. Free data may be incomplete/delayed; verify important fundamentals and prices before trading.
